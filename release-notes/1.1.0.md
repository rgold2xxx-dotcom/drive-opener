## What's new

- The installer is now available in English and Japanese (chosen automatically from your Windows display language)
- Shared drives and Other computers folders can now be found on Windows in other languages
- Added an English download page (README.en.md)

## 変更点

- インストーラーが英語・日本語の2言語になりました（Windows の表示言語で自動的に選ばれます）
- 「共有ドライブ」「その他のパソコン」のフォルダを、日本語・英語以外の言語の Windows でも見つけられるようにしました
- 英語の配布ページ（README.en.md）を追加しました
